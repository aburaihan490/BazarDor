# 🛍️ বাজার দর | BazarDor

BazarDor is a modern e-commerce platform designed to make online shopping simple, convenient, and accessible. Users can explore products, browse categories, view product details, and enjoy a smooth shopping experience through a responsive interface.

---

## ✨ Key Features

1. 📱 Responsive Design — Works smoothly on mobile, tablet, and desktop devices.
2. 🛒 Product Browsing — Explore products, browse categories, and view detailed product information.
3. 🔐 Authentication & Protected Routes — Secure access to protected pages with appropriate login redirects.
4. ⏳ Loading & Error Handling — Skeleton loading states, friendly 404 pages, and useful toast notifications.
5. 🚀 Dynamic Routing & Deployment — Dynamic product and category URLs designed to work correctly after deployment and page refresh.

---

## 🛠️ Technologies Used

- Frontend: React / Next.js

- Language: TypeScript / JavaScript

- Styling: Tailwind CSS

- Notifications: React Hot Toast

- Routing: Next.js App Router / React Router

- Deployment: Vercel

- Version Control: Git & GitHub
